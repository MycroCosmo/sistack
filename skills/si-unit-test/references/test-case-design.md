# 업무 기준 테스트 설계

목록: 전체 건수·빈 목록·검색·정렬·마지막 페이지. 등록: 생성 번호·작성자·필수 입력·길이 경계. 수정/삭제: 대상 없음·정상 저장 상태. 공통코드: 결과·페이지 매개변수. 날짜: 양 끝 경계·잘못된 범위.

먼저 종류를 분류한다. Service/유틸은 단위 테스트, Mapper는 실제 매핑과 테스트 DB를 연결한 좁은 통합 검사, 템플릿·설정·JS는 별도 계층 검사다. 실행 불가 로그 사례는 BLOCKED다. 가능한 사례 분모와 전체 표본 수를 함께 보고한다.

약한 테스트는 같은 대상 반환값을 null/상수로 바꾸거나 호출을 제거한 임시 변이로 검증한다. 원래 코드에서는 통과, 변이에서는 실패해야 한다. 실패가 컴파일이나 DB 준비 오류인 경우 탐지로 세지 않는다. 변이와 보강 기록은 eval에 두고 테스트베드에 정답 힌트를 넣지 않는다.
