# 06-sort-sql — 승인 전 정답 초안

위치(패치 적용 후): src/main/java/kr/sistack/board/domain/BoardSearch.java:67

원인: 허용된 외부 정렬 키 createdAt을 물리 컬럼 b.CREATED_AT으로 변환하지 않고 ${sortColumn}에 전달한다.

수정안: 허용 키를 검증된 컬럼 상수로 매핑한다. ${}를 #{정렬값}으로 바꾸면 컬럼 정렬 의미가 달라진다.

기대 상태: CONFIRMED. 기대 증거: 소스 검토 2~3단계, 재현 성공 시에만 4~5단계.

소거할 후보: 요청 경로·바인딩·인코딩·뷰 설정·DB 값 중 해당 증상을 설명하지 못하는 조건을 실제 소스로 확인한다.
