### 남은 문제

학습 연결 eval은 PASS지만 세 실행 manifest는 **PARTIAL**이다. 이번 정적 수집기 검증에서 앱·HTTP·DB를 다시 실행하지 않았고 외부 AOP/서버 override는 미확인이다. 앞선 테스트베드의 JDK 17/Maven JUnit 2건·3.1.5 렌더링·검색/등록/data AJAX/JSP 공존 검증은 [이전 기록](evidence/m2.5-testbed/verification.json)을 따른다. Thymeleaf 3.0 구문 분석 합격은 3.1 렌더링 호환성 보증이 아니다.

**Java 8 런타임은 BLOCKED**다. 구성된 실행 환경에 Java 8이 없다. 환경이 준비되면 해당 JAVA_HOME으로 `mvn -B -q -f examples/legacy-board-thymeleaf/pom.xml test`를 실행해야 한다. 삭제 AJAX의 실제 앱 동작과 두 신규 held-out 첫 점수는 아직 미검증이다. PetClinic 빌드/JPA 검증도 하지 않았다.

로컬 삭제 템플릿은 테스트베드 작성·이전 전체 인덱싱 입력에 포함돼 있었다. 해당 흐름의 개별 채점·튜닝은 하지 않았으나 외부 블라인드 표본으로 주장하지 않는다. 파서의 동적 식·복잡한 JS 전파·Boot 자동 뷰 설정 한계는 [limitations](limitations.md)에 기록했다.
