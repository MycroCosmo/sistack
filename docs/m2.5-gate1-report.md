### 결정

Java 8·Spring 5를 유지하기 위해 **thymeleaf-spring5 3.1.5.RELEASE + thymeleaf-layout-dialect 3.4.0**을 제안한다. Groovy 4.0.25를 포함하며 Thymeleaf 전이 중복 경로를 제외하고 SLF4J API를 2.0.17로 통일한다. 공통코드 목록은 JSP resolver(order 2, code/*), 나머지는 Thymeleaf resolver(order 1, board/*·login·error)로 선택한다. [결정 기록](decisions.md)에 남겼으며 아직 승인된 설정은 아니다.
