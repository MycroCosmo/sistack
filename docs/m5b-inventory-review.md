# M5b 독립 소스 대조 승인 기록

인덱서와 별도로 파일을 열거하고 인용 상태를 추적하는 source census로 선언 위치/종류/개수를 대조했다. 실행 코드/인벤토리 출력에서 기대 목록을 복사하지 않았다. 주석의 과거 AJAX 예시는 제외했다. 2026-10-28 Ian이 종류별 개수를 별도 수동 집계로 대조해 47/71 일치를 확인하고 정식 기준으로 승인했다.

두 프로젝트 모두 승인 기준 대비 누락/추가 0이다. 각각 선언 TC 47/71개와 업무 보충 TC 9개로 56/80개를 만들었다. 인벤토리↔선언 TC 누락/중복/고아 0이며, 알려진 URL·메서드는 기대 요청에 포함한다. 실제 id/name이 없는 항목의 실행 여부와 정적 선언의 누락 여부는 별도로 집계한다.

소스 파일별 SHA-256과 종류별 선언 위치는 [expected.json](../evals/functional/expected.json)에 있다. 자동 census 자체의 한계(지원 문법·정적 선언·원문 주석 구분)가 있으므로 임의 프레임워크/동적 DOM의 전수성을 보장하지 않는다. 승인은 이 두 고정 소스의 지원 문법 범위에 한정한다.

AGENTS.md 7절에 따라 승인자 Ian·승인일 2026-10-28·수동 집계 근거를 expected.json에 기록하고 초안을 확정했다. 실행 당시의 초안 상태 기록은 과거 run에 남겨 두고 최종 비교만 승인 기준으로 확인했다.

**팝업 실제 표본은 두 테스트베드 모두 0개다.** 누락 0은 실제 팝업 감지 검증을 뜻하지 않는다. 팝업 감지는 미검증으로 남기고, 검증용 테스트베드 화면 추가를 v0.2 백로그에 기록했다.
