# M5b 독립 소스 대조 초안

인덱서와 별도로 파일을 열거하고 인용 상태를 추적하는 source census로 선언 위치/종류/개수를 대조했다. 실행 코드/인벤토리 출력에서 기대 목록을 복사하지 않았다. 주석의 과거 AJAX 예시는 제외했다. 기준은 아직 사용자 미승인 초안이다.

| 종류 | legacy-board | legacy-board-thymeleaf |
|---|---:|---:|
| form | 6 | 7 |
| 버튼 | 8 | 13 |
| 핸들러 | 4 | 8 |
| AJAX | 2 | 4 |
| data-url | 0 | 2 |
| 링크 | 7 | 9 |
| fragment 선언/포함 | 12 | 19 |
| 팝업 | 0 | 0 |
| 숨김 필드 | 8 | 9 |
| 합계 | **47** | **71** |

두 프로젝트 모두 이 초안 대비 누락/추가 0이다. 각각 선언 TC 47/71개와 업무 보충 TC 9개로 56/80개를 만들었다. 인벤토리↔선언 TC 누락/중복/고아 0이며, 알려진 URL·메서드는 기대 요청에 포함한다. 실제 id/name이 없는 항목의 실행 여부와 정적 선언의 누락 여부는 별도로 집계한다.

소스 파일별 SHA-256과 종류별 선언 위치는 [expected.draft.json](../evals/functional/expected.draft.json)에 있다. 자동 census 자체의 한계(지원 문법·정적 선언·원문 주석 구분)가 있으므로 임의 프레임워크/동적 DOM의 전수성을 보장하지 않는다. 실제 소스 검토 후 정식 기준으로 승인해야 한다.

AGENTS.md 7절: “eval 정답은 사용자가 승인한 것만 정답으로 쓴다. 에이전트가 만든 초안은 expected.draft.*로 둔다.” 승인 전에는 DRAFT 비교로만 보고하며 기능 실행은 승인된 계정/차수로 계속한다.
