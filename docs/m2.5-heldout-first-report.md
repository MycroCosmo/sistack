PetClinic의 누락 4개는 다음과 같다. 승인 정답의 상태는 모두 CONFIRMED로 유지했다.

Boot 뷰 정답은 starter(:56), @SpringBootApplication(:28), application.properties(:7) 및 두 profile properties의 prefix/suffix 재정의 부재·WebConfiguration·파일 존재를 확인했다.
