# 수정 전 첫 실행 원본

- `results.json`: 학습 세트와 분리한 첫 held-out 연결 점수·누락·범위·실행 정보·해시.
- 세 사례의 `.md`: 첫 스킬 보고서 사본.
- `supplemental-review.json`: 보충 정답의 보고서 수록 여부와 미확정 경계. 연결 점수와 별도인 수동 자기 평가.
- `reverse-command.json`: 실제 `--to` 역방향 명령·종료 코드·출력 해시.
- `npm-test.log`: 65건 회귀 테스트와 승인 정답 무결성 검사 원본 로그.
- `originals.json.gz`: 59개 첫 실행 파일의 손실 없는 UTF-8 스냅샷. 골격·점수·역방향·검토·manifest·보고서·승인 정답·실행 드라이버를 포함한다. JSON 메타데이터 반복으로 diff가 커지는 것을 줄이기 위해 Node 표준 gzip으로 보존했다.

압축을 풀면 `{format, description, created_at, files}` 구조다. `files` 키는 당시 저장소 기준 상대 경로이며 각 값은 `{sha256, utf8}`다. `Buffer.from(entry.utf8, 'utf8')`가 원본 바이트이고 SHA-256과 일치한다. 저장 직후 압축 해제→파일별 해시→실제 원본 바이트 대조를 수행했다. 압축 파일·payload SHA-256은 results.json에 있다. 이 파일들은 기존 기록을 덮어쓰지 않는 경로에 생성했다.

첫 AJAX 전방 질의의 9/17과 전방+역방향의 17/17을 모두 보존한다. 발표한 점수는 사용자 지정 역방향 요구를 포함한 17/17이다. 보고용 trace는 요청 endpoint 범위만 남긴 결과이며 누락 연결을 추가하지 않았고 첫 자동 결과와 점수가 같다.

이 스냅샷은 소스·HTTP·DB 실행 성공의 증거가 아니다. 원본 파일 위치와 해시, 분석기 실행 및 에이전트 소스 확인 과정을 보존한 기록이다.

첫 AJAX 스킬 평가 레코드의 expected_sha256 일부는 기존 마스킹 코드 때문에 REDACTED로 저장됐다. 해당 결함도 원본 그대로 보존한다. 유효한 정답 해시는 첫 골격 기록과 압축 원본 안 expected.json 파일의 sha256에서 확인할 수 있고, results.json은 원래 기록값과 유효한 해시·출처를 함께 제공한다. 점수·정답 파일·구현은 변경하지 않았다.
