# program-list

상태: PARTIAL. 11행, 매핑 10열. 미확인 빈 칸 34개.
증거 단계: 소스 위치 2 / xlsx 저장·재읽기 4.
원본 해시 동일: true, 양식 보존: true, 입력 값 재확인: true.

## 경고
- 감지된 보존 범위 밖 요소 없음 (전체 OOXML 보장을 뜻하지 않음)

## 미확인
- 범위: endpoint당 1행. 런타임 도달·프로그램 ID·업무명 미확인; Service 표시는 클래스명 관례
- 인덱서가 해석하지 못한 동적 연결은 포함하지 않음
- 미확인 빈 칸 34개 (verification.json 참조)

## limitations
- 수식은 식과 캐시를 보존하며 계산하지 않음. Excel/LibreOffice 실제 표시·재계산 검증은 별도
- 피벗·차트·매크로·전자서명·외부 연결·도형·스레드 댓글·고급 확장은 보존 보장 안 함. 발견 시 PARTIAL 경고
- 검증 범위: 기본 드롭다운, 기본 조건부 서식, 병합, PNG 이미지, 셀 메모, 수식, 셀 서식, 다른 시트. 모든 OOXML 변형을 보장하지 않음
- 행 삽입/이동·자동 범위 확장 없음. 사용자 양식은 충분한 빈 입력 행과 end_row를 명시해야 함

셀별 빈 칸은 노란색과 evidence/verification.json에 표시. source_revision 및 파일 해시는 data.json 참조. 사용자 원본 양식의 식별자·내용은 이 보고서에 인용하지 않음.
